# SimpleStopwatch_8051
A simple stopwatch program written in Assembly for the Intel 8051 microcontroller. A university project. 
# How to use:
This stopwatch program counts time from 00,00 to 99,99 in seconds and centiseconds. Every 10 seconds the Buzzer turns on for brief time.
- Press "A" to pause the time, press it again to resume.
- Press "B" to reset the time to 00,00.
